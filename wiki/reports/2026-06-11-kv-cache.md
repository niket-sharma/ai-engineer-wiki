## ⚠️ Misconceptions (fix these first)

- Stated 'KV cache is the main memory bottleneck at long context' which may imply it grows directly with batch size — KV cache grows with sequence length (Gotchas / misconceptions)
- Claimed attention gives full parallelism during training without acknowledging the need for positional encoding due to lack of inherent positional order (Tradeoffs)
- The answer incorrectly focused on types of attention (bidirectional, causal) unrelated to Flash Attention, which is about optimizing compute and memory for attention operations
- Flash Attention is being incorrectly referenced as the mechanism for vLLM's paged attention. The candidate refers to Flash Attention, which is a different technique focused on training and compute efficiency, not serving and memory efficiency as in Paged Attention (Connections)
- The candidate stated that vLLM allocates KV cache in fixed-size pages like OS virtual memory, removing fragmentation and enabling prefix sharing, which raises GPU utilization and throughput. However, they emphasized prefix sharing as a source of increased GPU utilization, whereas it is the paged attention that allocates non-contiguous memory pages that allows for higher utilization (Paged Attention (vLLM)).
